开发路线图 & 成本预算

从零到盈利，分三步走

第一阶段：工具站 MVP（第 1 周）
交付：8 个代码工具上线，Google Analytics 接入，AdSense 申请提交
成本：域名 ~¥60/年，Vercel 免费，Cloudflare 免费
目标：日 UV 从 0 → 50
你需要：买域名 + 注册 AdSense + 部署到 Vercel
第二阶段：内容引擎 + 引流（第 2-4 周）
交付：内容自动生成脚本，知乎发布 8-12 篇，百度收录开始
成本：DeepSeek API ~¥10-50/月
目标：工具站日 UV 50 → 200，知乎粉丝 0 → 500
你需要：发布文章到知乎（我生成好你复制粘贴）
第三阶段：变现 + 扩展（第 5-12 周）
交付：AdSense 开始有收入，图片工具接入，会员系统上线
成本：Replicate/Cloudflare AI API ~¥50-200/月
目标：工具站日 UV 200 → 1000+，月收入 ¥100 → ¥3000+
你需要：开通支付接口（微信/支付宝商户）
