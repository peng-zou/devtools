## 技术选型

| 层 | 技术 | 原因 |
|---|------|------|
| 前端 | Next.js + React + Tailwind CSS | SEO 友好，Vercel 原生支持 |
| 部署 | Vercel（免费）+ Cloudflare DNS | 零成本起步 |
| 后端 | Vercel Serverless Functions（后期） | 按需付费 |
| 内容 | Python 脚本 + DeepSeek API | 低成本内容生成 |
| 分析 | Google Analytics + Umami | 免费额度够用 |

## 第一批工具（8 个纯前端代码工具）

1. **JSON 格式化/校验** — 美化、压缩、错误定位（对标 jsonformatter.org，月访问 250 万）
2. **正则表达式测试器** — 在线写正则、实时测试、常用正则库（对标 regexr.com，月访问 48.7 万）
3. **Base64 / URL 编解码** — 文本 ↔ Base64 ↔ Unicode，支持图片
4. **色码转换/调色板** — HEX ↔ RGB ↔ HSL 互转 + 色板生成
5. **时间戳转换** — Unix 时间戳 ↔ 日期，多时区（CSDN ⭐⭐⭐⭐⭐）
6. **文本差异对比** — 逐行 diff，代码版本对比
7. **UUID/随机字符串生成** — SEO 长尾词
8. **Markdown 在线预览** — 即时预览，SEO 长尾词

每个工具一个独立 SEO 页面，纯前端实现，零后端依赖。
